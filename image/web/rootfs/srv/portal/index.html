Se connecter (device code)

Les jetons sont conservés dans le volume /home/dev : ils survivent à la recréation du container.

Azure CLI
az login --use-device-code
Azure Developer CLI
azd auth login --use-device-code
Az PowerShell
Connect-AzAccount -UseDeviceAuthentication
Microsoft Graph
Connect-MgGraph -UseDeviceCode -Scopes "User.Read.All"
Exchange Online
Connect-ExchangeOnline -Device
Microsoft Teams
Connect-MicrosoftTeams -UseDeviceAuthentication
PnP PowerShell
Connect-PnPOnline -Url https://<tenant>.sharepoint.com -DeviceLogin -ClientId <app-id>
CLI for Microsoft 365
m365 login --authType deviceCode
GitHub CLI
gh auth login
AKS (Entra ID)
az aks get-credentials -g <rg> -n <cluster> && kubelogin convert-kubeconfig -l azurecli
